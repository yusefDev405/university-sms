# Application Security Controls (OWASP Mapping)

| Risk | Potential Attack | Control & Exact Location |
| :--- | :--- | :--- |
| **SQL Injection** | Malicious SQL injected via query params, filters, or sort keys | 100% parameterized `$1, $2` queries across all `backend/src/modules/*/repository.js`; sort columns strictly whitelisted in `backend/src/utils/pagination.js`; static check enforced via `scripts/lint-sql.js`. |
| **Broken Object-Level Authorization (BOLA)** | Student drops another student's enrollment, or Instructor grades/reads another instructor's offering | Service-layer ownership checks in `backend/src/modules/enrollments/service.js` (`dropEnrollment`), `offerings/service.js` (`getOfferingRoster`, `getGradeDistribution`), `grades/service.js` (`setSingleGrade`, `setBulkGrades`), and `students/service.js` (`getStudentById`), verified in `backend/tests/authorization.test.js`. |
| **Broken Function-Level Auth (RBAC)** | Student invokes admin endpoints (`POST /courses`, `GET /audit-log`) | `authenticate` (`backend/src/middleware/auth.js`) + `requireRole(...)` (`backend/src/middleware/requireRole.js`) mounted on every protected route. |
| **Token Theft & Replay** | Stolen refresh token replayed after rotation | Refresh tokens are 256-bit random values stored only as SHA-256 hashes (`backend/src/utils/tokens.js`) in `refresh_tokens`; rotation revokes old token and replay of a revoked token revokes the entire `family_id` (`backend/src/modules/auth/service.js`). |
| **CSRF on Cookie Endpoints** | Cross-site form posts to `/auth/refresh` or `/auth/logout` | Cookies use `HttpOnly`, `SameSite=Strict`, scoped to `path: '/api/v1/auth'`, plus mandatory `X-Requested-With: XMLHttpRequest` header check in `backend/src/middleware/csrf.js`. |
| **Credential Stuffing & Weak Passwords** | Brute-force login attempts or uniform timing/enumeration leaks | `bcryptjs` cost 12 (`db/scripts/seed.js`, `users/service.js`), minimum 8-char password schema, generic `"Invalid email or password"` error, automatic 15-minute lockout (`429 ACCOUNT_LOCKED`) after 5 consecutive failures (`auth/service.js`), and stricter `/api/v1/auth` rate limit (`backend/src/app.js`). |
| **Mass Assignment** | Client injects `"role": "admin"` or extra fields in JSON body | All Zod schemas use `.strict()` (`backend/src/modules/*/schema.js`) validated in `backend/src/middleware/validate.js`. |
| **XSS & Misconfiguration** | Script injection, open CORS, stack trace leakage | JSON-only API, React automatic escaping, `helmet` strict CSP + origin-restricted `cors` (`backend/src/app.js`), `errorHandler.js` omits stack traces, secrets read from `.env` (`backend/src/config/env.js`). |
| **Sensitive Data Exposure** | Leaking `password_hash` or bearer tokens in API or logs | Explicit column projections exclude `password_hash`; `backend/src/utils/logger.js` recursively redacts `password`, `password_hash`, `authorization`, `cookie`, `token`. |
| **Accountability** | Untracked grade/enrollment edits | PostgreSQL `audit_row()` trigger (`db/migrations/004_triggers.sql` & `006_attendance_and_rules.sql`) logs `actor_user_id`, `old_data`, `new_data` into `audit_log`; `requestIdMiddleware` attaches `X-Request-Id`. |
| **Vulnerable Dependencies** | Outdated npm or GitHub Actions dependencies | `npm audit --audit-level=high` in `.github/workflows/ci.yml`, lockfiles, and `.github/dependabot.yml`. |
